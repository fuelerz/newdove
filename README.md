# Dove Nest animated website

Mobile-first website for Dove Nest, Bandh Santa Cruz, Goa. Includes dark mode, animated PNG floaters, WhatsApp booking, Google Maps review flow, responsive gallery filters, and expandable gallery structure for adding more photos later.

To add more gallery pictures: place the image in `assets/`, copy an existing `<figure class="gallery-item" data-category="...">` block inside `frontend/gallery.html`, update the image filename, alt text, and category.
